# Code of Conduct

zakdroid-code adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. It applies in all project spaces: issues, pull requests, discussions and reviews.

In short:
- Be respectful and patient. Many contributors are students and beginners.
- Criticize code and ideas, never people.
- No harassment, insults, discrimination, sexual content, or publishing others' private information.
- Write in English or Modern Standard Arabic so everyone can follow.

## Reporting
Report unacceptable behavior to the project maintainer, GitHub account `studyzakomi-oss`. You can also use GitHub's **Report content** option on the comment or issue.
Reports are handled privately. The maintainer may edit or remove content, and may warn or block participants, as described in the Contributor Covenant's enforcement guidelines.
